Clauze Website — Image Guide

Exactly which images to buy from Freepik and where each one goes. All dimensions and search terms included.

How to use this guide: Buy the images from the Freepik links below (most are Premium, ~$1 each on a subscription). Once downloaded, open clauze-website.html and replace each /* IMAGE SLOT */ comment with the file path or a hosted image URL. Each card below maps to one slot in the website.

How to replace an image in the HTML file

1
Buy and download the image from Freepik. Upload it to your hosting or use Cloudinary/Imgix for CDN.
2
Find the image slot comment in clauze-website.html (each is labeled with the slot name below).
3
Replace the placeholder CSS with the real image URL:
/* Before */
background: #1E293B; /* SLOT: hero-bg */

/* After */
background-image: url('your-image-url.jpg');
background-size: cover;
background-position: center;
